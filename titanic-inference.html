TITANIC INFERENCE

Creative Dev 2D Canvas API Machine Learning Flask

The Titanic dataset is the "Hello World" of data science. Instead of a boring HTML form, I built a fully playable, gamified web experience. Users board an isometric ship, control a pixel-art passenger, and trigger real-time ML survival predictions.

Role Creative Dev
Timeline Sept 2026
Year 2026
Status Deployed
(MY ROLE)

Built a custom 2D isometric game engine from scratch using HTML5 Canvas and Vanilla JS.

Developed a Python/Flask backend to serve game assets and host the ML prediction endpoint.

Engineered complex collision matrices and a custom integrated map-painting tool for the browser.

Handled lazy-loading protocols and multi-threading for seamless full-screen cinematic transitions.

Approach

01

The Game Engine

Instead of an off-the-shelf engine, I built the frontend from scratch, managing dynamic cameras and a sprite-sheet state machine for character animations.

02

Isometric Math

Wrote custom math to perfectly align a 200x200 diagonal collision matrix, preventing characters from walking through walls on a simulated breathing ocean.

03

ML Integration

Wired the game state directly to a Flask backend. Submitting your passenger class and ticket triggers the live ML probability model.

04

Cinematic Payoff

Integrated heavy .mp4 crash cinematics, utilizing strict lazy-loading to ensure the single-threaded JS game loop never dropped a frame.

(PART 01)

Killing the Form

Bridging the gap between a standard data science pipeline and a custom interactive game engine pushed me far out of my comfort zone.
