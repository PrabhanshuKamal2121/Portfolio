(CASE STUDY · 03)

CUSTOMS MANAGER

Full Stack AI YOLO NLP NLTK

An end-to-end, multi-modal AI-powered customs clearance and cargo auditing platform for Fractal Overseas. It combines natural language processing with advanced computer vision to automate and secure international shipping logistics.

Role Full Stack AI
Timeline May 2026
Year 2026
Client Fractal Overseas
(MY ROLE)

Built a Scikit-Learn NLP pipeline using TfidfVectorizer to cross-reference descriptions with HS codes.

Trained a custom Ultralytics YOLO model for automated object detection on X-ray cargo scans.

Implemented statistical Z-score analysis to flag severe over-invoicing discrepancies.

Integrated document OCR for automated manifest ingestion.

Approach

01

Manifest Ingestion

Automated the extraction of unstructured text from shipping manifests using OCR, eliminating hours of manual data entry.

02

NLP Classification

Cross-referenced extracted item descriptions against official HS tariff codes using semantic matching and TF-IDF vectorization.

03

Vision Auditing

Deployed a YOLO computer vision model to scan X-ray images of baggage and cargo, ensuring visual contents match the written manifest.

04

Fraud Detection

Utilized statistical anomaly detection (Z-scores) to automatically flag pricing and invoicing discrepancies for human review.

(PART 01)

Multi-Modal Compliance

Bridging the gap between textual data analysis and visual cargo inspection to create a unified, AI-driven compliance ecosystem.
